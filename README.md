# AI for Manufacturing webinar landing page

A small React and Vite starter for a premium industrial AI webinar page.

## Run locally

1. Install Node.js (18 or newer).
2. Run `npm install` in this folder.
3. Run `npm run dev` and open the local address Vite prints.

## Project map

- `index.html` — page metadata and the React mount point.
- `src/main.jsx` — starts the React application and loads the styles.
- `src/App.jsx` — the landing page content.
- `src/styles.css` — theme, layout, and responsive styling.

The first page is intentionally a single component. As the page grows, sections such as the agenda, speaker, and registration details can be split into small components.
